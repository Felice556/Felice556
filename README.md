## ⭐ Main Project — FT Coach

**A mobile-first web app for personal trainers and their clients.**
I created it for my own coaching work: I prepare training plans, my clients log every set from their phone at the gym, and I follow their progress in real time.

🔗 **[Live app](https://ft-coach.pages.dev)** · **[Frontend repo](https://github.com/Felice556/ft-coach-frontend)** · **[Backend repo](https://github.com/Felice556/ft-coach-backend)**

**What it does**
- 📋 **Training plans**: the trainer builds plans with sets, rep ranges, rest times, notes and exercise videos
- 📱 **Workout mode for clients**: log weight and reps set by set, with a rest timer (sound, volume, ±10/15s, screen kept awake)
- 📈 **Progress tracking**: charts per exercise and per workout, with personal records
- ⚖️ **Body composition**: clients log body weight, the trainer logs body-fat %, both with charts
- 👥 **Trainer dashboard**: completed workouts, full history of each client, archived plans (data is never deleted)
- ✉️ **Invite-only sign-up**: single-use, expiring invite codes shared via WhatsApp
- 🌗 **Light / dark theme** and **installable PWA**

**Under the hood**
- **Frontend**: React, TypeScript, Vite, Tailwind CSS v4, Recharts — deployed on Cloudflare Pages
- **Backend**: Node.js, Express 5, TypeScript, Prisma 7, PostgreSQL (Supabase) — deployed on Render
- **Security**: JWT sessions that can be revoked (password change logs out every device), bcrypt, rate limiting on login and sign-up, Helmet and Content-Security-Policy headers, strict input validation with Zod, per-client data isolation
- **Privacy**: GDPR notice and explicit consent for health data, EU-hosted database
- **Testing**: 100+ automated tests (Vitest, Supertest) on a real PostgreSQL database, run on every push with GitHub Actions
